# Dispensationalism Atlas

Interactive historical atlas tracing the history of Dispensationalism from the Plymouth Brethren to the present.

**[Live Demo](https://garridolecca.github.io/dispensationalism-atlas/)**

## Features

- 30+ historical locations across Europe and the Americas
- 4 color-coded eras: Early Roots, Spread & Systematization, Classical Dispensationalism, Revised & Progressive
- 15 key figures: Darby, Scofield, Chafer, Walvoord, Ryrie, Moody, and more
- Bilingual interface (English / Spanish)
- Interactive ArcGIS map with zoom-based label collision detection
- Timeline panel, figures panel, and detailed bottom sheet navigation
- Mobile-friendly with touch gestures

## Tech Stack

- ArcGIS Maps SDK for JavaScript 5.0
- Calcite Design System
- Esri World Light Gray Canvas basemap tiles (no API key required)
- Google Fonts (Cinzel + Inter)
- Vanilla JavaScript (ES Modules)

## Getting Started

```bash
npx serve .
```

Then open the local URL in your browser.
